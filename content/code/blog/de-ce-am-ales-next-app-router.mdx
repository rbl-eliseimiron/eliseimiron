## Motivația

App Router permite componente server implicite, ceea ce simplifică citirea
fișierelor MDX direct din sistemul de fișiere, fără un strat suplimentar de API.

```ts
export async function getPostBySlug(section: SectionSlug, slug: string) {
  // citește fișierul .mdx și îl compilează la build/request time
}
```

## Ce urmează

- Migrarea articolelor reale dintr-un export WordPress (XML → MDX)
- Adăugarea de componente MDX custom (embed-uri de cod, imagini optimizate)
